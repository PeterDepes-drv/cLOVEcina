Nastavenia Firebase

Pre prepojenie rodiny v reálnom čase na viacerých zariadeniach je potrebné nakonfigurovať Firebase Realtime Database. Konfigurácia sa ukladá iba vo vašom prehliadači (localStorage).

Ako získať databázu zadarmo za 3 minúty?

  1. Navštívte Firebase Console.
  2. Vytvorte si nový bezplatný projekt (kliknite na Pridať projekt).
  3. Zaregistrujte Webovú aplikáciu (ikona </>) v nastaveniach projektu.
  4. Skopíruj hodnoty z vygenerovaného objektu firebaseConfig sem.
  5. V ľavom menu otvorte Realtime Database a vytvorte databázu.
  6. V záložke Rules (Pravidlá) prepíšte kód na:
    { "rules": { ".read": true, ".write": true } }
